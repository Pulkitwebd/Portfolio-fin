# Rashi Shakya Portfolio (React)

- Edit your content: `src/data/portfolio.json`
- Run locally: `npm install` then `npm run dev`
- Build: `npm run build` (output in `dist/`)
- Deploy: upload `dist/` to Netlify / Vercel / GitHub Pages
  (Vercel/Netlify: build command `npm run build`, output folder `dist`)
- Images and resume PDF go in `public/`
